MAT 102A · Test 1 · Definitions & Equations

One-page aid · no examples

Data structure

Individual — person or object studied.
Population — entire group of interest.
Sample — subset of the population studied.
Variable — characteristic measured or recorded.
Data — the observations collected.
Parameter — numerical summary of a population.
Statistic — numerical summary of a sample.
Lock: Population → Parameter · Sample → Statistic

Variable type

Categorical — labels or categories.
Quantitative — numerical amounts.
Discrete — countable quantitative values.
Continuous — measurable quantitative values.

Levels of measurement

Nominal — names, no order.
Ordinal — ordered categories; differences not meaningful.
Interval — equal differences; no meaningful zero.
Ratio — equal differences + meaningful zero; ratios valid.
Order: N → O → I → R = Name → Order → Interval → Ratio

Sampling methods

Simple random — every individual equally likely; drawn from a complete list.
Stratified — population split into subgroups; sample taken from every subgroup.
Systematic — random start, then every k-th individual.
Cluster — random whole groups selected; all members surveyed.
Convenience — individuals easiest to reach.
Multistage — selection through successive stages.
Trap: stratified = some from every group; cluster = all from selected groups.

Bias

Sampling bias — method systematically favors certain outcomes.
Undercoverage — part of the population inadequately represented.
Nonresponse bias — selected individuals do not respond, and responders differ systematically from non-responders.
Response bias — answers given are systematically distorted.
Data-entry error — information recorded incorrectly.

Study type

Observational study — researcher observes and records; no treatment assigned.
Experiment — researcher assigns treatments.
Explanatory variable — used to explain or predict the response.
Response variable — outcome measured.
Confounding — effect of the explanatory variable cannot be separated from another variable.
Causation: observational data support association only; a randomized controlled experiment can support causation.

Experiment vocabulary

Experimental unit — person or object receiving a treatment.
Factor — variable manipulated by the researcher.
Level — specific value or category of a factor.
Treatment — experimental condition applied (a level, or combination of levels).
Response — outcome measured on each unit.
Randomization — units assigned to treatments by chance; balances other variables across groups.
Replication — each treatment applied to many units.
Control — hold outside variables fixed; comparison/control group.
Principles: control → randomize → replicate

Graph selection

Bar graph — categorical data; bars separated; categories may be rearranged.
Pareto chart — bar graph with categories ordered highest → lowest frequency.
Pie chart — categorical; parts of a whole.
Histogram — quantitative data; bars touch; numerical order fixed, cannot be rearranged.
Stem-and-leaf / dot plot — quantitative; retains individual values.

Center

Mean — arithmetic average; uses every value; sensitive to extreme values.
Median — middle value of ordered data; resistant to extreme values.
Mode — most frequent value or category; may be none or several.
Rule: with outliers or strong skew, the median better represents a typical value; symmetric data → mean ≈ median.

Spread

Range — distance from smallest to largest; uses only two values.
Variance — mean squared deviation from the mean; units squared.
Standard deviation — square root of the variance; typical distance of a value from the mean, in original units.
IQR — spread of the middle 50% of the data; resistant.
Read: small SD = values clustered near mean; large SD = values spread out. SD ≥ 0; SD = 0 only if all values identical.

Position & outliers

z-score — number of standard deviations a value lies from its mean; unitless, so it compares values from different distributions.
z > 0 above the mean · z < 0 below · z = 0 at the mean · larger |z| = farther from the mean.
Quartiles — Q1 25th percentile, Q2 median (50th), Q3 75th percentile.
Percentile — value at or below which that percent of the data fall.
Potential outlier — any value below the lower fence or above the upper fence.
Five-number summary — minimum, Q1, Q2, Q3, maximum; basis of the boxplot.

Frequency equations

relative frequency = f / n
percentage = relative frequency × 100%
pie angle = relative frequency × 360°
Σ (relative frequencies) = 1

Center equations

μ = Σx / N
x̄ = Σx / n
Median: order the data. n odd → the middle value; n even → mean of the two middle values.
Median position = (n + 1) / 2 in the ordered list.

Spread equations

range = maximum − minimum
σ² = Σ(x − μ)² / N
σ = √[ Σ(x − μ)² / N ]
s² = Σ(x − x̄)² / (n − 1)
s = √[ Σ(x − x̄)² / (n − 1) ]
Population divides by N; sample divides by n − 1.

z-score equations

population: z = (x − μ) / σ
sample: z = (x − x̄) / s
Larger z = farther above its own mean; compare z values, not raw scores.

Quartile & outlier equations

Q2 = median of all data.
Q1 = median of the lower half; Q3 = median of the upper half (omit Q2 itself when n is odd).
IQR = Q₃ − Q₁
lower fence = Q₁ − 1.5(IQR)
upper fence = Q₃ + 1.5(IQR)
Outlier test: x < lower fence or x > upper fence.

Exam loop

Who? → What variable? → What type & level? → How chosen? → Bias? → Observational or experiment? → Graph or summary → Calculate → Interpret in context.
