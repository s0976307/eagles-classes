## Course outline (instructor's framing)

The SDLC — the textbook calls it the *systems development process framework*.

1. **Waterfall (plan-driven / phased)**
   - Envision & Plan: identify/select project · preliminary investigation (feasibility)
     · business case · project charter · statement of scope · work breakdown structure
   - Analysis — *the WHAT*: elicit requirements; structure them via process model,
     data/domain model, logic model, HCI model
   - Design — *the HOW*: architecture · output · input · database · human interface
   - Construct (or configure)
   - Test: alpha, beta, unit, integration, system, acceptance
   - Implement (release / deploy)
   - Maintain (operational support)
2. **Agile (iterative)** — Scrum and Kanban: plan (user stories) → build (analysis +
   design + construct + test) → release
3. **Hybrid** — assess project characteristics (radar chart) · preliminary analysis
   (intelligent modeling: BDUF, BRUF) · iterative construction
4. **Generative AI** is an explicit course topic.

The instructor also adds project-planning content and structured-development concepts
**not in the textbook** — lecture notes matter for exams.
