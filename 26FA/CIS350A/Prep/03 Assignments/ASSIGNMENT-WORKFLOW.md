# Assignment workflow & intake template

Each assignment gets its own folder here. Copy the template below into
`<folder>/prompt-and-plan.md` when the Canvas instructions post.

## Standing requirements (every assignment)

- Submit a **Word .docx** to Canvas.
- Diagrams drawn in **draw.io**, exported PNG, pasted into the doc. No freehand.
- Due **11:59 pm Saturday**. −10% per day late. Extensions granted on request — ask
  before the deadline, not after.
- Keep the `.drawio` source in `04 Diagrams/drawio source/` and the export in
  `04 Diagrams/exported png/`.
- Drop a copy of the exact submitted file into `06 Submitted/`.

## Order of work

Requirements → model → blueprint → draw.io → Word → review → submit.
Never open draw.io first. The boxes are rarely the problem.
