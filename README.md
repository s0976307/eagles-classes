# Eagles Classes

Coursework from Niagara University (Purple Eagles), Computer and Information
Sciences, digital forensics track. Organised by term so a finished semester
stops competing for attention with the live one.

## Layout

```
26FA/          Fall 2026 (current)
  CIS350A/     Intro to Systems Analysis and Design
  MAT102A/     Statistics
  HIST/        HIS 110 C, US presidential history
26SP/          Spring 2026: statistics case studies and final project
25FA/          Fall 2025
_INFLIGHT/     Work not tied to a term: research papers and notebooks
```

Term folders are named `<YY><FA|SP|SU>`. Course folders use short course codes
to keep Windows path lengths safe.

## Highlights

| Item | Where |
|---|---|
| Systems analysis assignments: activity diagram, ER diagram, user stories, UI wireframe | `26FA/CIS350A/Prep/03 Assignments/` |
| Chapter notes and modelling reference | `26FA/CIS350A/Prep/02 Readings and Notes/` |
| Statistics case study on sleep data | `26FA/MAT102A/` |
| Statistics case studies and final project proposal | `26SP/` |
| AI and digital forensics research project | `_INFLIGHT/` |
| ALPR governance paper (proposal and sources) | `_INFLIGHT/ALPR_Governance_Paper/` |
| Data structures notebooks (Jupyter) | `_INFLIGHT/` |

## How the work is done

Each assignment gets its own folder. `prompt-and-plan.md` holds the task and
rubric verbatim plus open questions, and `answer-scaffold.md` lays out the
structure. The order of work is fixed (see `ASSIGNMENT-WORKFLOW.md`):

```
requirements -> model -> blueprint -> draw.io -> Word -> review -> submit
```

AI assistance is used as a tutor and is cited where the course requires it
(see `26FA/CIS350A/Prep/01 Syllabus and Course Info/AI-CITATION-FORMAT.md`).

## What is not here

Instructor-owned material (lecture decks, textbook, exams, instructor tools)
and personal student records are kept out of this repository.
